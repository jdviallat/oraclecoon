# Oraclecoon — mises à jour & binaires

Dépôt **public** de distribution de l'application **Oraclecoon** (par Bengacoon) —
l'oracle des 104 animaux totems.

- 📱 **Télécharger l'APK** → [Releases](https://github.com/jdviallat/oraclecoon/releases/latest)
- 🌐 **Site officiel** → https://jdviallat.github.io/oraclecoon-site/
- 🔒 **Politique de confidentialité** → https://jdviallat.github.io/oraclecoon-site/politique.html

## Contenu

| Fichier | Rôle |
|---|---|
| `latest.json` / `version-android.json` | manifestes de mise à jour interrogés par l'app |
| `version-web.json` | manifeste de la version web |
| `index.html`, `politique.html`, `acheter.html` | redirections vers le site officiel (anciennes URL, conservées pour les versions déjà installées) |

> Seul l'**APK public** est distribué ici. Les AAB Play Store et les builds iOS partent
> directement vers Google Play et l'App Store, jamais sur GitHub.
>
> Le **code source est privé**.
